# 验证方法与可复现证据

本文件说明**规范里那些"必须这么做"的规则是怎么验出来的、以及你怎么自己复验**。
**不含任何具体样品/项目数据**——所有可复现数字都来自合成谱、纯公式推导或运行时内省。

## 1. 三类证据

| 类型 | 怎么产生 | 例子 |
|---|---|---|
| **运行时内省** | 读上游包的源码/元数据，与文字描述对照 | 元素参数默认值、自由参数个数、`fixed` 状态；`Ls` 的注册 `equation` 与 `_impedance` 实现不一致 |
| **合成谱实验** | 造一条已知真值的谱，看流程能否把它找回来 | 参数回收；剖面固定到真值；把撒点范围当硬边界会夹紧参数；`tanh`/`exp` 溢出 |
| **纯公式/文献** | 解析推导或引用原文 | `Y_W = Y^n`；`f_cross ≈ 1/(2πB)`；`R = 2(-Z'')_peak/tan(nπ/4)`；AICc 的 `k` 口径；Boukamp 权重定义 |

**不把"某一条具体数据的拟合结果"当证据**：那种数字换一份数据就不成立，写进规范会变成误导。

## 2. 怎么自己复验（每条都能在几分钟内跑完）

| 规则 | 复验方法 |
|---|---|
| 元素公式/默认值/`fixed` | `pyimpspec.get_elements()` + `fit_circuit(...).get_parameters()` 打印 `value/fixed/unit`；与自己写的 `z_model` 逐点比 |
| `Ls` 公式以**实现**为准 | 数值点核对：用注册 `equation` 与 `_impedance` 各算一次，看是否差数十 % |
| 两阶段不牺牲准确性 | 同一 `seed` 跑 `two_stage=True/False`，比 `best_sse`（应一致到 ~1e-14）与耗时 |
| 解析 Jacobian 正确 | `eis_core.py --selftest` 的 `[3b]`：与中心差分逐列比，列归一化误差应 < 1e-9 |
| 撒点范围 ≠ 硬边界 | 造真值 `n=0.85` 的合成谱，把 logit 撒点范围当硬边界跑一次：`n` 会被夹到 `0.7311`、最大残差 3.73 %；放宽后回到 0.85、最大残差 0.000 % |
| `profile` 的 grid 是 θ 空间 | 传物理值 `0.85` 而不用 `to_theta`：会静默固定成 `sig(0.85)=0.70`，SSE 从 ~1e-30 变到 ~1e-4 且不报错 |
| 最低 SSE 解可能是退化解 | 看 `params_on_hard_bound` 与 `params_outside_plausible_range`；再看 `best_valid_*` 的最大残差是否明显更小 |
| 参数口径会虚报解数 | 看 `n_distinct` vs `n_distinct_spectrum`；不可辨识方向上的漂移会让前者远大于后者 |
| K-K 判据要用逐点最大值 | 同一谱分别取 max 与 RMS：RMS 可以 <0.5 % 而单点 >1 % |
| 表示法影响判据 | 同一谱用 Z 与 Y 表示法各跑一次 `perform_kramers_kronig_test`，比较逐点最大值 |
| pyimpspec 的 `num_RC` 互斥 | 指定 `num_RC` 且不关 `F_ext` 搜索 → 直接抛 `ValueError` |
| CDC 标签语法 | `R_1{R=20}` → `InvalidElementSymbol`；`R{R=20:sol}` → 名称 `R_sol` |
| 参数注入不能静默失败 | 把 R1 改成一个离谱值，看谱是否真的变；不变就说明键没匹配上 |
| `pseudo_chisqr` 是二次口径 | 用拟合结果自己算 `Σ|ΔZ|²/|Z_exp|²`，与 `pseudo_chisqr` 对；再算 L4 看比值（**比值不是常数**） |
| AICc 必须先给初值 | 用软件默认初值排名一次、用物理初值再排一次：排名会整体翻转 |
| `Tlmbo` ≡ 重参数化 `Wo` | 用 `z_cdc` 两个电路各算一次、逐点比；注意必须把 `Wo.n` 显式设成 `n/2` |
| 输出物命名合规 | `init_case.py` 生成骨架后跑 `validate_eis_outputs.py`，应为 0 违规；再故意改个非法文件名验证它能抓到 |

## 3. 仍然只是"推理"、没有被运行时验证的部分

1. **上游元数据与实现不一致**（`Ls` 的 `equation`、`Wo`/`Ws` 的 `B` 单位）：以本机 `_impedance` 实现为准，换版本必须重跑内省。
2. **L4 目标是否是上游有意设计**：只能观察到"lmfit 最小化的是 L4、报告的是二次口径"这一事实，动机需上游确认。
3. **`n ≤ 1` 的软件默认上限**：这是约定，不是物理定律（`n = 1` 即理想电容）。
4. **加权拟合下的 1σ 带**：`SSE_best + SSE_best/dof` 要求残差独立、近似同方差，加权后只是近似量。
5. **嵌套 F 检验在边界/指数消失时的渐近分布**：不成立，必须用 bootstrap 校准。
6. **多进程提速**：Windows 是 spawn，从脚本/REPL 直接调用会因缺 `if __name__ == "__main__":` 抛 `RuntimeError`；要并行请自行包主模块，规范不替你做这个决定。

## 4. 容易复发、已被否掉的疑点（别重复踩）

1. K-K 噪声公式里的 `√1.5` **是对的**（蒙特卡洛可复现 `mean(std(d)) = √1.5`）；`√6` 只用于没有除以 2 的二阶差分。
2. `Tlmno`/`Ls` "漏算串联 R" 的说法**撤回**，参数计数本来是对的。
3. "表观电感 2.9 倍低估"是**局部两点比值**，不构成缺陷。
4. 把 `Tlm` 的自由度说成"不能为 0"**撤回**：`L` 默认固定、其余在子电路里。
5. `Auto` 的方法数不是 8：是 **9 方法 × 4 权重 = 36**。
6. "装不上 deareis 是镜像缺包"**撤回**：多数是国内源正常、本机 pip 索引缓存过期，加 `--no-cache-dir` 即可。
7. "`Wo` 与 `W` 共用同一个 `Y` 就等价"**撤回**：必须 `Y_W = Y^n`（退化时 `Y^n` 才成立）。
8. "L4/L2 有个固定换算系数"**撤回**：`pseudo_chisqr` 本身就是二次口径，比值随残差量级变。
