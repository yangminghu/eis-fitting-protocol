# EIS 元素与公式参考

pyimpspec / deareis 运行时内省结果 + 文献公式。本文件**不含任何具体样品/项目数据**：所有可复现数字都来自合成谱或纯公式推导，可用 `eis_core.py --selftest` 与自己手上的数据复核。

## 1. CDC 语法

- `[ ]` 串联 `Z = ΣZ_i`；`( )` 并联 `Z = (ΣZ_i⁻¹)⁻¹`
- 例：`R(C[RW])`（Randles）、`[RL(RQ)(RQ)Wo]`
- 扩展（初值/限值/标签）：`R{R=20/15/35}`、`Q{Y=1.6e-5,n=0.78:dl}`、`R{R=100f:sol}`（`f` = 固定）
- 嵌套：`R{R=20}(R{R=13}Q{Y=2e-5,n=0.8})(R{R=5}Q{Y=4e-8,n=0.98})`
- 坑：参数名须写全（`R{20}`→`ExpectedParameterIdentifier`）；R、Q 分开写（`(RQ{R=13,Y=..})` 报 `InvalidParameterDefinition ('R') for 'Q'`）；参数间逗号、元素间无分隔符（`;` 报 `UnexpectedCharacter`）
- **元素标签只能写在花括号内**：`R{R=20:sol}` → `get_name()` = `R_sol`；写 `R_1{R=20}` 会抛 `InvalidElementSymbol: Invalid element symbol 'R_1'`，`R{R=20:1}` 会抛 `UnexpectedToken`（数字标签非法）
- **`R_1` 这类编号名不是 CDC 语法**：`fit_circuit` 的参数名是 `R_1`/`L_1`/`R_2`/`Q_1`/`R_3`/`Q_2`/`Wo_1`（同符号按出现次序编号），而 `parse_cdc` 对无名元素的 `get_name()` 只给 `R`/`Q`（**重名**）。只认后者会让"按 `PARAM_NAMES` 注入参数"**静默失效**（`eis_core.element_index(circ)` 同时提供两种别名并让未知名大声报错）
- **自由参数个数 / 固定状态的可靠来源**：`pyimpspec.fit_circuit(circ, data).get_parameters()` → `{"R_1": {"R": FittedParameter(value, stderr, fixed, unit)}, ...}`，`k` = 非 `fixed` 的个数（`[RL(RQ)(RQ)Wo]` 里 `Wo_1.n.fixed=True` ⇒ k=10）。**`Element` 实例没有 `get_parameters()`**（只有 `get_values()`/`set_values()` 与 `_parameter_fixed` 等描述符），别照直觉写

## 3. `Wo` 退化与 n 是否固定

- `W`/`Wo`/`Ws`/`G`/`Ga` 的 `n` 默认 `fixed=True`、0.5（45° 约定、**可检验假设非物理定律**）
- `Wo` 的 `coth` 自变量 `x = (B·2πf)^n`；`B·2πf ≫ 1`（B = 时间常数，s）时 `coth→1` ⇒ `Wo → 1/[Y^n(i2πf)^n]`（**非** `1/(Y(i2πf)^n)`）
- 与 `W = 1/(Y_W(i2πf)^n)` 对上须 **`Y_W = Y^n`**：用 `Y_W=Y` 在高频段可差 **3000 %** 量级，用 `Y_W=Y^n` 则到机器精度
- 拐点 **`f_cross ≈ 1/(2πB)`**，非 `1/(2π·B^(1/n))`（仅 n=1 一致）；`f_cross` 不在测量窗口内 ⇒ **B 不可辨识**，唯一测量量是 `Y^n`（CPE 口径）
- n 判定流程：默认 0.5 与放开 n 比 SSE → 对 n 做剖面似然 → **频率子集检验**（去掉最低/最高频十倍频后重拟）。`SSE(0.5)/SSE(n_best) < 1.5` ⇒ 用 0.5；> 2 且各子集一致 ⇒ 放开并作拟合量报告；偏离只来自某子集 ⇒ 说明 n 由该段决定，须写明并做删段敏感性检验
- 渐近相角 = −n·90°：0.5 → 理想半无限扩散的 −45°；< 0.5 → 更平，通常是非理想扩散（多孔/弛豫时间分布/表面膜/混合控制）。**n 是唯象参数**，机制结论需要别的表征佐证
- 放开 n 会打开 `Y_Wo↔B_Wo` 简并：n 可估，**`B_Wo` 仍不可辨识**，`R_Wo = (B/Y)^n/3` 只是外推量（且仅 n=0.5 时是低频实部极限）

## 4. 分组说明与选型

- **无源**：`R` 欧姆/电荷转移电阻（当欧姆电阻用须有"频率无关"的物理理由）；`C` 双电层、表面不均匀改用 `Q`；`L` 引线/夹具电感；`La` 用于高频相角明显小于 90° 时（`n` 接近 1 就退化成理想 `L`，加它未必值）
- **常相位族**：`Q` n=1 理想电容 / n=0 理想电阻 / 0.5<n<1 压扁半圆；`Zarc` = `R(Q)` 的合并写法（与 `R(Q)` 二选一报告）。`C_eff` 必须写明用哪一支：**峰时标** `C_eff = τ/R = Y^(1/n)·R^(1/n−1)`（单个并联 `R(Q)`，由 `τ = (R·Y)^(1/n) = 1/ω_peak` 反解，不是 Brug）；**Brug** `C_eff = Y^(1/n)·(1/R_s+1/R_p)^((n−1)/n)`（多孔/粗糙电极；拓扑一变公式就得换）。**不可**把 `Y` 直接当电容报（`S·s^n` 含 n）
- **弧高与 R 的反解**：`(-Z'')_peak = (R/2)·tan(nπ/4)` ⇒ **`R = 2(-Z'')_peak/tan(nπ/4)`**；只取"两倍峰高"相当于假设 n=1，n=0.8 时会低估约 **27 %**。重叠弧的局部峰不能当独立过程
- **Warburg 族**：一直 45° 不弯 → `W`；上翘后趋于竖直平台（阻塞）→ `Wo`；上翘后回勾（穿透）→ `Ws`；窗内 `B·2πf ≫ 1` ⇒ 三者都退化成 `W`（须 `Y_W = Y^n`）、B 不可辨识。`coth(x)` 一律写 `1/tanh(x)`（`cosh/sinh` 在高频溢出）
- **反应+扩散**：`G` 高频 45°、低频趋实轴，适合混合导电骨架/多孔/电催化；`Ga` 是同一过程的 R-τ 参数化，与 `Ha`/`Zarc` 形状相近 ⇒ 靠低频相角与整体形状判别，**别靠 AICc 微差**。`H`/`Ha` = HN 族（`a=b=1` 退化成 Debye），4 参数强相关、单弧时 `Q` 更稳
- **多孔族**：`Ls` 的 `R_i`(Ω/cm)、`R_r`(Ω·cm)、`Y`/`n`（孔壁 CPE）、`d`(cm)（孔长）互相补偿 ⇒ **至少固定其中一个**（本规范固定 `d`、`R_r`）。`Tlm` 自身只固定 `L`，内容在 5 子电路，自由度 = 子电路参数之和，最灵活也最容易过拟合；6 个预置里 `Tlmbo`/`Tlmbs`/`Tlmbq` 阻塞、`Tlmno`/`Tlmns`/`Tlmnq` 非阻塞（含 `R_ct`），后缀 o/s/q = 外边界开路/短路/CPE。预置参数带 `/m`、`·m` 量纲，**不可与普通 R、Q 横向比较**
- **`L` 的标度**：传输线阻抗只经无量纲 `ω_L = 1/(R_i·Y·L²)^(1/n)` 依赖 `L`，存在精确尺度变换使阻抗逐点不变 ⇒ 固定 `L = 1 m` 不损失一般性；但 **`R_ct`、`R_B` 不是与 L 无关的绝对量**（`L` 加倍则同一谱给出 `2×R_ct`），报告须与 `L`、`R_i`、`Y` 同列 <!-- 单位与标度易误读 -->
- **选型**：①非多孔/厚膜 → `Q`/`Zarc` 就够、不上传输线；②无法拉第反应 → Blocking，有 → Nonblocking；③低频竖直平台 → Blocking、趋实轴 → Nonblocking；④参数已经很多但残差仍高 ⇒ **先做可辨识性检验**，别继续加元素

## 6. 拟合方法

**权重**（`deareis.enums.Weight`）：`Unity` `w = 1`；`Modulus` `w = 1/|Z_fit|`（相对误差、EIS 常规；**分母是拟合值**）；`Proportional` Re/Im 各 `1/Re(Z_fit)²`、`1/Im(Z_fit)²`（**虚部趋 0 时发散**，`Z''` 过零的谱慎用）；`Boukamp` `w = 1/|Z_exp|²`（Boukamp 1995 eq.13，用实测值、更重压小阻抗点）。**不同权重的 SSE/χ² 不可直接比较**，比模型须换算到同一目标函数。

**目标函数口径**：自写骨架是 `Σ|ΔZ/|Z||²`（**L2**）；pyimpspec 的 `_residual` 先把分量误差平方、lmfit 再求平方和 ⇒ **被最小化的是 L4**：`Σ(ΔRe⁴+ΔIm⁴)·w²`。

- **`FitResult.pseudo_chisqr`（报告值）不是这个函数**：它是二次口径 `Σ(|ΔRe|²+|ΔIm|²)·w²`（在 `modulus` 权重下等于 `Σ|ΔZ|²/|Z_exp|²`，可用自己的数据逐位验算）。
- **两者比值不是常数**：它随残差量级变化，所以**不存在"L4↔L2 换算系数"**，任何单一比值的说法都不能当普适常数。
- 推论：报告"拟合目标"必须把 `weight` 与 `form` 分开写；**不同口径的数值不得直接比较**。

**参数变换**：正量（R/L/C/Y/B/k）→ `p = 10^θ`；指数 n → `n = 1/(1+e^{−θ})`（logit）；限范围参数 → θ 空间 box 约束。理由：避免优化器撞墙（负值/越界）并使各参数量级相近；代价是 logit 端点饱和、`10**θ` 可能溢出。

**初值反解**（禁用软件默认值 R=1000 Ω、L=1 μH、Q.Y=1e-6、Wo.Y=1、B=1 —— 用默认值很容易掉进垃圾极小）：

| 参数 | 反解式 |
|---|---|
| `R_ser` | 最高频几点 `Z'` 平均 |
| `L` | **`dZ''/dω` 最小二乘斜率**（保守、偏低）；`Z''/ω` 只看最高频 1–2 点，**勿用频段均值**（该段非单调，§11） |
| `R_k` | **`R_k = 2(-Z'')_peak/tan(nπ/4)`**（n 未知先按 0.8–0.95 迭代）；`2(-Z'')_peak` 只在 n=1 成立，n=0.8 时低估 **27 %** |
| `f_peak` | 该弧 `−Z''` 极值对应的频率 |
| `Q.Y` | **`Y ≈ 1/[R_k(2πf_peak)^n]`**（由 `τ = (R·Y)^{1/n} = 1/(2πf_peak)` 反解）；**勿写 `(2πf_peak)^n/R_k`**（上下颠倒，可差 10⁶–10⁸ 倍） |
| `Q.n` | 先给 0.8–0.95，由多起点覆盖 0.5–1.0 |
| `W.Y` | 低频 −45° 段估 σ ⇒ `Y_W = 1/(σ√2)`（**仅** n=0.5 且 `W` 用 σ 参数化时） |
| `Wo.Y` | 高频极限 `1/[Y_o^n(iω)^n]`；对 `W` 须 **`Y_W = Y_o^n`**；n=0.5 时 `Y_o = 1/(2σ²)`（**不是** `1/(σ√2)`） |
| `Wo.B` | **B 是时间常数（s）**：`B ≈ 1/(2π·f_cross)`；**勿写 `√(1/(2π f_min))`**（量纲错）；`f_cross` 不在窗口内 ⇒ 直接说"B 不可辨识" |
| 传输线 `R_i` | 量级取该弧电阻（`Z_TLM ~ R_i`），`Y` 由 `f_peak` 反解 |

**多起点**：起点数按参数个数取（≤8 → ≥200；9–12 → ≥300；≥13 → 500–1000）；撒点在对数空间（正量）与 logit 空间（指数）均匀随机、覆盖 2–4 个数量级；按 `rtol=0.05` 聚类并**报去重后的解族**；只能写"**已发现的最低 SSE**"与"**解族**"、**勿写"确认全局最优"**。**`Auto` 只穷举 9 方法 × 4 权重 = 36 次拟合、不做多起点**，解决不了局部极小；**已知解必须作种子**（显式 `starts[0]`、超界参数**逐分量裁剪**而不是整条丢弃）。

**速度（v6 默认，实测方法见 §14）**：`global_fit` 默认走**两阶段**——① 全部起点用松容差粗筛（`screen_tol=1e-4`、`screen_nfev=1000`）；② 粗筛解按阻抗口径粗去重成"盆地代表"，只对最好的 `refine_top=20` 个用紧容差精修（`tol=1e-12`、`max_nfev=5000`）。同一 `seed` 下 `best_sse` 与单阶段（`max_nfev=20000`）一致到 ~1e-14，耗时降到约 1/2–1/7。若筛完发现"无贴界解"缺失，加大 `refine_top` 或把 `screen_tol` 放宽（≡ 保留更多样的盆地代表）。`jac="analytic"` 可再省掉每轮 `n_param+1` 次差分评估，但在病态起点多的合成问题上反而更慢，故默认是 `"2-point"`。

**数值稳定性**：`coth` 写 `1/tanh`；复数幂用 `(1j*w)**n`（n→0 注意分支）；logit 端点饱和 ⇒ 参数停在 0.999+/1e−3 附近时按**触界**处理（改用 `bounds` 约束）；残差加 `np.isfinite` 保护；参数极端时 pyimpspec 抛 `InfiniteImpedance` ⇒ 拟合循环必须 `try/except`，否则多起点会中断；**报告用的谱必须在"只用最优参数新建的对象"上重算**（优化中对象被反复改写，直接用会把"最后一次残差评估"的参数当最优上报）；顶界参数**不报对称 ±1σ**；`bounds` 必须真传给求解器（`np.clip` 会形成平坦目标面）；**撒点范围 ≠ 硬边界**——用合成谱可复现：把 logit 撒点范围 `lo=0,hi=1` 当硬边界会把真值 `n=0.85` 回收成 `0.7311`、最大残差 3.73 %；放宽到 `logit∈[−6,6]` 后 `n` 回到 0.85、最大残差 **0.000 %**、SSE ~1e-30。

**退化要按两个层次查（缺一层就会漏报）**：①**贴硬边界**——θ 到硬边界距离 ≤ 1e-3；②**跑出物理合理窗口**——正量分量的 θ 超出撒点窗口 `START_LO/HI`（`eis_core` 报为 `params_outside_plausible_range`）。只看①会漏掉"某个串联电阻被推到比合理窗口低 8 个数量级、但离硬下界还差 0.65 个 log10"这类**事实退化**。同一个 `global_fit` 结果里，无前缀字段描述**最低 SSE 解**、`valid_` 前缀描述**无贴界解**，两者常是不同解，**不要混报**。

**拟合够不够好（合格性）**：把**最大**相对残差与 E4 的噪声量级比。最大残差与噪声同量级 ⇒ 模型够用；**大一个数量级以上、或残差呈系统性频段偏差** ⇒ 该模型对本谱不合格，必须明说并继续换模型（E12/E13），**不得直接给参数结论**。只看 RMS 会掩盖这种失败——RMS 可以很小而单点/某频段残差很大。

**输入体检（先做）**：`eis_core.check_data(f, z, n_param)` 一次拦住长度不一致 / 空 / 非有限值 / 非正频率 / **重复频率** / `|Z| = 0` / **自由度不足（2N ≤ 参数个数）**。这几类在旧流程里会以 `ValueError: zero-size array to reduction...`、`best_sse = inf`、或"10 个参数拟合 1 个点得到 SSE ~1e-23"这种**看似成功**的方式出现，属于静默错误。

**多份数据批量核查**：`scripts/scan_batch.py <目录> --starts=200 --csv=spread.csv`；它输出逐文件 JSON + **参数组间离散度表** + 合格性统计（E18/E16）。

**收敛后验证**：① 用最优参数在新建对象重算 `Z_fit`，与优化器报告的残差对照；② 用 `fit_circuit` 从同一初值再拟一次、参数应一致到 < 1 %；③ R > 0、0 < n ≤ 1、L 在高频给正确感性符号、直流极限与最低频实测 `|Z|` 量级相符。

**弧数（几个 RQ 块）怎么定**：**不要**只看 `Z''` 的原始逐点极值个数——它不抗噪、不可复现：对同一条谱，原始计数、不同宽度的滑动平均、不同显著性阈值能给出互相矛盾的个数。两个必须避免的做法：①**用全频段 σ 当绝对阈值**——真实谱上 `prominence > 3σ_all` 常常恒等于 0，等于什么信息都没有；阈值要**相对化**，例如 `prominence > max(3σ_本频段, 2 % × 该点 |Z''|)`。②**只报一个数字**——必须同时报「平滑宽度 w / 阈值口径 / 该口径下的极值个数」，让它只作**描述**。弧数最终由 **AICc（同权重同口径、每个候选模型先给物理初值 + 多种子）+ 分频段残差结构**决定，而且要先过下面的"合格性"筛。

**多份数据 / 重复测量**：同一体系的多份谱要**逐份独立走 s1–s4**（先平均再拟合会把系统漂移伪装成低噪声）；必须报**组间离散度**，并与谱内噪声比较——**组间差异通常比谱内噪声大 1–2 个数量级，它才是主导不确定度**；跨样品/跨状态的参数比较必须超过该离散度才有意义。若某份给出退化解（串联电阻趋 0、指数贴界）而另一份正常，**必须报告这个不一致**并说明模型/约束不稳健，不得只挑"最好看"的那份报。

## 7. Kramers–Kronig 校验

K-K 是线性/因果/稳定系统的**充要条件**，但仅对**无限频带、连续、无噪声**的谱成立 ⇒ Lin-KK 只是**一致性诊断**（残差小 = 没发现不一致，**不等于**证明平稳）；谱确实不满足 K-K 时等效电路参数没有物理意义。

```
Z_KK(f) = R_ser + Σ_{k=1..M} R_k/(1 + i·2πf·τ_k)   [+ i·2πf·L_ser]
τ_k 在窗口内对数分布：τ_min = 1/(ω_max·F_ext)，τ_max = F_ext/ω_min；F_ext = 端点延拓因子
权重：模量加权；残差 δ = (Z_data − Z_fit)/|Z_data|
μ = 1 − Σ_{R_k<0}|R_k| / Σ_{R_k≥0}|R_k|     （只对 M 个 RC 求和，不含 R_ser/L_ser）
```

- 表示法：`admittance=None` ⇒ **在 Z 与 Y 之间自动择一**；`test` 可选 `real / imaginary / complex / cnls`
- 加 C/L：默认均 `True`；含高频感性段的谱**必须加串联 L**，否则高频残差假性偏大
- F_ext：默认**自动搜索** `log_F_ext`（`−1.0`…`1.0`、20 次评估），**并非固定 1**
- **报告必须写清上述四项配置**，否则任何"残差 X %"都不可比
- 判据是**逐点最大相对残差而非 RMS**：**逐点** |ΔRe|、|ΔIm| 均 < **1 %**（分母 `|Z|`）；RMS 小不能保证没有单点超标；1 % 是经验阈值，最终要与**噪声量级**比较
- **表示法会影响判据**：同一份谱在 Z 与 Y 表示法下逐点残差可以不同，判据取**做等效电路拟合的那个表示法（Z）**，并把两种表示法的结果都报出来
- `M ≈ 0.5–1.5 N`（N = 点数）；**必须报告 μ(M) 与 χ²(M) 两条曲线**（扫 M = 0.25N → 1.5N）并**固定所选 M**
- **μ 只作旁证、不是判据**：`μ_crit = 0.85` 是过拟合阈值；数据平滑、且已用 R_ser/L_ser 抽掉两个单调趋势后，μ 会随 M 增大单调趋 0、**失去分辨力**。与"扫 M 看残差是否已到噪声水平"冲突时**以残差为准**
- **pyimpspec API 契约**：指定 `num_RC` 时必须同时给 `num_F_ext_evaluations=0` + `log_F_ext`，否则抛 `ValueError`；`perform_exploratory_kramers_kronig_tests` 的 `num_RCs` 必须留空
- 噪声与离群：点对点噪声（二阶差分）`σ ≈ std(Z_i − (Z_{i-1}+Z_{i+1})/2)/√1.5`（给 Ω 与 %|Z| 两口径）；离群阈值 `max(|Re 残差|,|Im 残差|) > max(3σ_robust, 1 %)`；低频 1–2 个点偏大常是长时漂移，**不要急着删**（那往往正是约束扩散的数据）

## 8. 不确定度与模型比较

**不要用雅可比协方差**：高阻+多参数的 EIS 问题里 `JᵀJ` 常严重病态（条件数可达 10²¹ 量级、数值秩亏），雅可比协方差会给出荒谬误差（要么大到没意义、要么给出虚假的几位小数）。改用：

1. **残差 bootstrap（主）**：残差重采样后加回模型、重做完整拟合 **N ≥ 200** 次（有界参数每次也在同界内重拟合），取 16/84 分位数。**须写清 4 件事**：①重采样的是**加权残差**还是按误差模型生成的噪声；②整体重采样还是**按频段分块**（残差有自相关时必须块 bootstrap）；③Re/Im 两分量**成对**还是各自独立；④每次重拟合的**起点策略**（从最优解出发会低估不确定性）。**N 与"每次重拟合起点数"是两个独立参数**，都要报。成本很高，可用两阶段精修与并行（自行包 `__main__`）压低。
2. **剖面似然（判可辨识性）**：固定一个参数于一系列值、每次**把它从优化向量里删除**、重优化其余参数，画 SSE vs 参数；**1σ 带 ≈ `SSE_best + SSE_best/dof`**（dof = 2N − k，dof 小时按 `F` 真值修正）。带仅一两个**网格点**宽 ⇒ 被数据约束，但宽度依赖网格密度（须报网格范围与取点方式）；带覆盖 **1–4 个数量级** ⇒ 不可辨识、只能报区间；**无法收敛回参考 SSE** ⇒ 先怀疑实现/起点，别当成"模型更差"的证据。该阈值要求残差满足独立/近似同方差模型，**加权拟合下 1σ 带只是近似量**。⚠️ 剖面工具的 **grid 是 θ 空间**（指数先 logit、正量先 log10），直接传物理值不报错、只会把参数固定到错值。

**模型比较 AICc**：`AICc = n·ln(SSE/n) + 2k + 2k(k+1)/(n−k−1)`，`n` = 残差分量数（复数残差堆叠时 2×点数）；`k` 取 `fit_circuit(...).get_parameters()` 里**非 `fixed` 的个数**（若用 `n·ln(SSE/n)` 则 `k` 再加 1，把共同方差 σ² 也当被估计量）。前提与陷阱：

- **先过合格性、再排名**：AICc 只能在同一批"残差已达噪声量级"的候选之间比。如果连最优候选的最大相对残差都比噪声大一个数量级以上，说明**这一族电路都不合格**，此时给 ΔAICc 排名是自欺——应报"全部不合格"并换电路族/补数据。- **每个候选模型都必须先按 E6 给物理初值、再按 E8 多种子，而且初值要按该模型的参数含义分别给**（拿同一组数值套到所有拓扑上会给某些模型一个坏起点，排名会被起点而非模型质量决定），否则 AICc 比的是"各模型各自落到的局部极小"。用软件默认初值直接排名可以把**错误拓扑**排到第一，而且换初值后排名会整体翻转 —— 所以"排名"本身必须与初值策略一起报告。
- **ΔAICc < 2** ⇒ 统计等价、不能宣布胜者；嵌套时同时报 F 检验但**须查前提**（删掉整个 RQ 块、参数停边界如 R → 0、或删掉的指数在剩余模型里不可辨识时，普通 F 的渐近分布不成立）⇒ 改用**参数 bootstrap / 似然比 bootstrap** 校准。
- **ΔAICc 是相对比较量不是置信概率**；比较必须**同一权重、同一频率子集、同一残差口径**（统一用 `pseudo_chisqr` 即可，但要知道它是二次口径，见 §6）。
- **AICc 不反映物理合理性**：ΔAICc 很小的两个模型要按"是否有可辨识的扩散特征"等物理判据讨论。

## 9. 常见陷阱清单

1. **不核实元素公式就开拟合** → 参数个数与定义都可能错（`Ls` 就是这样）。
2. **用软件默认初值** → 掉进垃圾极小；默认 `R = 1000 Ω` 与真实欧姆电阻常常差几个数量级。
3. **只跑单起点** → 错失更低的极小；多起点的瓶颈是**起点覆盖**而不是求解方法。
4. **AICc 或 χ² 跨权重直接比较** → 无意义。
5. **把不可辨识参数当测量值报告** → `B_Wo` 常在几个数量级内不可区分、`R_Wo` 是外推；串联电阻也可能漂到 ≈0。`R_Wo = (B/Y)^n/3` 只在 n=0.5 时是 `Wo` 的低频实部极限；n ≠ 0.5 时实部按 `ω^(−2n)` 发散、**不存在有限 `R_dc`**。
6. **忽略串联 RQ 块的置换对称性** → 互换标签阻抗不变、"谁是谁"只是约定；报告须声明约定（如 `τ₂ > τ₃`）。
7. **高频直接用 `L = Z''/(2πf)`** → 表观电感会随频率漂移（同一条谱取不同频点可以差几倍）；漂移本身不是"无串联 L"的证明（§11）。
8. **`coth` 用 `cosh/sinh`** → 高频溢出、莫名 NaN。
9. **中文 Windows 默认编码读带 BOM 文件** → GBK 报错；用 `utf-8-sig`。
10. **用 PowerShell `Get-Content -Raw | Set-Content` 改中文 UTF-8 文件** → 文件会被写坏。
11. **参数顶在边界上还引用误差条** → 不可靠（Wald 区间在边界无意义）。
12. **只报 RMS 不查残差系统性结构** → 必须画残差 vs log f 看有没有频段性偏差。
13. **低频 1–2 个点残差偏大就直接删** → 常是漂移，而且往往正是唯一约束扩散的数据；保留 + 做"删该点"敏感性对照。
14. **把 `Wo` 当成一定可辨识** → 窗口没覆盖拐点 `f_cross ≈ 1/(2πB)` 时 `Wo` 就退化成 `W`、报 `R_Wo` 是误导。
15. **不加检验就固定（或放开）`Wo` 的 n** → 必须做剖面似然 + 频率子集检验（§3）。
16. **把 `n_Wo` 的物理含义直接当"扩散机制"** → n 只是相角形状的唯象参数。
17. **多孔体系硬用 `R(Q)`** → 等效电容大得不符合几何预期时就是模型用错了，应改试 `Tlm*` 或 `Ls`；反之平整电极 + 液态电解液不该上传输线。
18. **传输线长度参数处理不当** → `L`/`d` 与 `R_i`、`Y` 互相补偿，至少固定其中一个（本规范固定 `L = 1 m`）。
19. **多起点没把已知解作种子** → 同一模型换个脚本会给出不同答案；做法：显式作 `starts[0]`、**逐分量裁剪**、打印确认。
20. **报告用的谱复用了被优化改写的对象** → 拿到的是"最后一次残差评估"的参数，会出现 SSE 与残差图对不上的怪象；用最优参数在**新建对象**重算。
21. **只看 AICc 就宣布某族模型"没用"** → 必须做**参数族可辨识性检验**。两类失败要分开：①模型形式不对；②参数不可辨识。判据见 §10。

## 10. 多孔 / 传输线模型能不能用：四步判据

1. **比 ΔAICc 与最大残差（不只看 SSE）**：ΔAICc > 10 且 SSE 明显下降 ⇒ 值得进一步查；ΔAICc < 2 ⇒ 统计等价、选参数少的；SSE 降了但**最大残差反而升** ⇒ 改善集中在某频段、不是全局改善，必须做分频段残差表；只有某窄带改善而低频/高频变差 ⇒ 新增自由度在"填"那一带的系统性偏差，要问这个偏差有没有物理含义。
2. **算特征频率、看是否落在测量窗口内**：传输线类元素的阻抗只通过**特征频率**与频率相关（`ω_L = 1/(R_i·Y·L²)^(1/n)`，`f_L = ω_L/2π`）。`f_L` 在窗口内 ⇒ 多孔特征留下可测印记、参数值得保留；远在窗口外（尤其低于最低频）⇒ 该元素已经退化成别的简单元件。**⚠️ `Tlmbo` 与重参数化 `Wo` 解析恒等**：令 `n_Wo = n/2`、`B = 1/ω_L`、`Y_Wo = B/R_i^(1/n_Wo)`，`Z = R_i/α·coth(α)`、`α = (iω/ω_L)^(n/2)` 与 `Wo` 全频段逐点相等（可用 `eis_core.z_cdc` 自己验到机器精度）⇒ **它不是独立物理模型，不可当作多孔结构的独立证据**。做这个等价时**必须显式把 `Wo.n` 设成 `n/2`**（`Wo.n` 默认 fixed=0.5，漏掉它时 n≠1 的 `Tlmbo` 会"看起来不等价"，这是典型的静默错）。省事的判定法：把孤立元件阻抗与候选解析式逐点对比。
3. **对关键多孔参数做剖面似然**：固定 `f_L`（或 `R_i`、`n_B` 等）、重优化其余全部参数，看 1σ 带宽。带很窄 ⇒ **参数可辨识**、多孔描述被数据支持；带覆盖 1–4 个数量级 ⇒ 不可辨识、只是自由度，不能作为结果报告；**无法收敛回参考 SSE** ⇒ 先怀疑实现/种子。⚠️ 横轴是 θ 空间的值（指数先 logit、正量先 log10），直接传物理值只会把参数固定到错值。
4. **查有无参数跑飞或顶界**：`R` 大得离谱/`n ≥ 0.999`/`R ≈ 0` 都是"很可能跑飞"的信号（阈值要用该模型自己的量级定，不能照抄某个数字），须用剖面确认。处置：①报告注明；②优先选**没有跑飞参数**的那一族。

## 11. 电感扣除判据

```
Z_corr(f) = Z_meas(f) − i·2πf·L
```

理想串联电感**只有虚部** ⇒ `Z'` 完全不变；**不要**用 `Z''/ω` 的均值估 `L`（该段非单调）。**`L` 不能直接采用等效电路拟合给出的值**——拟合 `L` 与校正用的 `L` 出自同一模型，拿它校正再评价是**自证**、不是独立验收。把它降为一个候选，与另两个一起比：

① 高频段 `dZ''/dω` 的最小二乘斜率（保守、**偏低**，作下界）；
② 使**顶部十倍频内 `Z''_corr` 保持单调不增**的最大许可 `L`（作上界，`L ≤ min(dZ''/d(2πf))`）；
③ 等效电路拟合给出的 `L`（自洽，但可能偏大）。

**验收必须同时满足两条**：(a) 校正后（模型不含 `L`）的 Lin-KK **逐点**残差下降且不超过噪声水平；(b) 顶部频段 `Z''_corr` 单调不增 —— 否则"校正"本身会制造假弧。**μ 只作旁证**。校正后的数据与"为什么不用拟合值"必须一起落盘。

## 12. 快速诊断表：症状 → 该试哪个元素

| 现象 | 建议尝试 |
|---|---|
| 高频 `Z'' > 0`、`Z''/ω` 随频率明显漂移 | `La` 替 `L`；或放开高频接触过程的 n |
| 压扁半圆、n 明显 < 1 | `Q`（已用 `C` 则换 `Q`） |
| 等效电容大得不符合几何预期 | `Tlm*` 或 `Ls` 替 `R(Q)` |
| 低频 45° 直线不弯 | `W` |
| 低频上翘后趋于竖直平台 | `Wo` |
| 低频上翘后回勾 | `Ws` |
| 低频尾巴"扁而不陡"、`B` 不可辨识 | `Wo` 但放开 n；或试 `G`；最好补测更低频 |
| 高频 45° + 低频实轴极限 | `G`（Gerischer） |
| 两段弧但 `Q` 拟不像（低频段系统性偏差） | `Ha` 或 `Zarc` |
| 只有一个大弧 + 低频 45° | `Ls` 或 `Tlmbo` |
| 多孔电极且有法拉第反应 | `Tlmno` / `Tlmnq` |
| 参数已很多、残差仍高 | **先做可辨识性检验**、勿继续加元素 |

## 13. 交叉验证 / 双实现互证

至少两条独立实现：一条官方 API、另一条自写 numpy + scipy。**比较前必须统一目标函数口径**（官方 API 最小化 L4、自写脚本通常是 L2，§6）：**交叉代入口径** —— 把官方解代进二次目标、把自写解代进 L4 目标，比较"**同一口径下的最优值**"，并证明差异能由目标函数解释；**在此之前不要用数值差异判定"某条实现错了"**。同一口径下两者应一致到 **3–4 位有效数字**。

**元素级对照**用 `eis_core.compare_official(cdc, p, f)`：写**不带标签**的 CDC（如 `[RL(RQ)(RQ)Wo]`），元素名由 `element_index` 提供 `<符号>_<序号>` 别名；**参数名对不上会抛 `KeyError`**（不静默降级 —— 静默跳过会退化成"拿 CDC 内联初值和自己比"，得到无意义的 ~1e-16）。官元素实现与自写实现重合到机器精度时，还要配一个**注入敏感性对照**（改一个参数后谱必须真的变）来证明这个比较不是空转。

## 14. 可复现的自检数字（合成谱，不含任何样品数据）

`python eis_core.py --selftest` 会自己跑出下面这些数字；换机器/换版本后**以本机输出为准**：

| 检查 | 期望 |
|---|---|
| 参数回收（含串联 RQ 置换对称） | PASS；`R1/L1/R2/Y2/n2/R3/Y3/n3/Yw/Bw` 回到真值，最大残差 < 1e-3 % |
| 多起点最低 SSE（61 点合成谱） | ~1e-30（机器精度量级）；无参数贴硬边界、无跑出合理窗口 |
| 剖面似然（固定 n2 到真值） | SSE ~1e-30；固定到错误 n 时显著变大，且横轴必须用 `from_theta` 换回物理值 |
| 解析 Jacobian vs 中心差分 | 列归一化误差 < 1e-9 |
| 与 pyimpspec 官方实现的元素级对照 | max 相对偏差 ~1e-16 |
| 官方对照的注入敏感性 | 改一个参数后谱必须变化 ≫1e2（否则对照是空转） |

**两阶段速度的可复现验证**：同一 `seed` 下 `global_fit(..., two_stage=True)` 与
`global_fit(..., two_stage=False, max_nfev=20000)` 的 `best_sse` 应一致到 ~1e-14；耗时前者约为后者的 1/2–1/7（比例随问题难度变，合成谱上差距更大）。
