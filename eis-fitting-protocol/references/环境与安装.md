# 环境与安装

## 1. 目录结构（WorkBuddy 技能规范）

```
eis-fitting-protocol/
├── SKILL.md
├── references/
│   ├── 元素与公式.md
│   ├── 器件元素清单.json
│   ├── 实测依据.md
│   ├── 环境与安装.md          ← 本文件
│   ├── LICENSE               ← Apache-2.0 官方正文（随包分发时请保留）
│   ├── NOTICE                ← 版权归属 + 第三方依赖清单
│   └── 许可与第三方声明.md     ← 中文摘要 + 第三方依赖（GPL）声明
└── scripts/
    ├── eis_core.py            ← 拟合核心（自带 --selftest）
    ├── init_case.py           ← 生成合规案例骨架
    ├── validate_eis_outputs.py← 输出物命名/manifest 校验器（C1–C9）
    ├── scan_batch.py          ← 多份数据批量核查（E18）
    ├── check_eis_env.py       ← 环境检查（--json / --check-mirrors / --print-install）
    ├── install.py             ← 安装到本机技能目录
    └── check_package.py       ← 打包自检（对照本页第 1 节的结构）
```

## 2. 安装

```bash
python scripts/install.py                        # 装到 ~/.dsh/skills/eis-fitting-protocol
python scripts/install.py --target <技能目录>    # 自定义技能目录
python scripts/install.py --force                # 覆盖已装版本
```

装完会打印实际路径；新开一次会话即可被列入技能目录。
**手动安装**同样简单：把整个 `eis-fitting-protocol/` 目录复制成
`<技能目录>/eis-fitting-protocol/`（目录里必须直接看到 `SKILL.md`）。

**验证安装**：

```bash
python "<技能目录>/eis-fitting-protocol/scripts/eis_core.py" --selftest
```

期望 `SELFTEST PASS`（参数回收 + 解析 Jacobian 校验 + 官方实现对照）。

> **不装依赖也能用**：`scripts/` 的脚本与 `references/` 的手册都是独立的，
> 把 `SKILL.md` 当提示词交给任意 AI 也可以。**只跑 `eis_core.py` 与 `init_case.py` 只需要 numpy/scipy。**

## 3. 依赖与版本锁定

只在"官方 API 对照 / 元素内省"时才需要 pyimpspec 与 deareis：

```bash
python scripts/check_eis_env.py          # 先查本机有没有（required / official / optional 三级）
python scripts/check_eis_env.py --json   # 一行 JSON（给 AI 看，省 token）
python scripts/check_eis_env.py --print-install   # 打印可直接粘的安装命令
python scripts/check_eis_env.py --check-mirrors   # 测国内镜像连通性
```

建议用**独立 venv**，别装进 anaconda base（会连带升级 numpy/scipy/matplotlib）：

```bash
python -m venv .venv_eis
.venv_eis\Scripts\activate            # Linux/macOS: source .venv_eis/bin/activate
python -m pip install -U pip
python -m pip install -r requirements-eis.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# ↑ 先把下面第 3 节的锁定清单存成 requirements-eis.txt（本包不再单独放这个文件）
```

锁定版本（存成 `requirements-eis.txt` 即可直接 `pip install -r`）：

```
# EIS 拟合技能包依赖（pyimpspec 5.2.0 的 METADATA 约束 + deareis 5.1.3 的依赖）
# 安装：python -m pip install -r requirements-eis.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# 或者不用文件，直接一行装齐：
#   python -m pip install "deareis==5.1.3" "pyimpspec==5.2.0" "numpy>=2.5" "scipy>=1.17" "matplotlib>=3.11" "lmfit>=1.3" "sympy>=1.14" -i https://pypi.tuna.tsinghua.edu.cn/simple
# ↑ 先把下面第 3 节的锁定清单存成 requirements-eis.txt（本包不再单独放这个文件）
# 若报 No matching distribution found：加 --no-cache-dir（是本机 pip 索引缓存过期，不是镜像缺包）
deareis==5.1.3
pyimpspec==5.2.0
lmfit>=1.3,<2
numpy>=2.5,<3
scipy>=1.17,<2
matplotlib>=3.11,<4
sympy>=1.14,<2
requests~=2.33
dearpygui~=1.11; python_version <= "3.12"
dearpygui==2.2;  python_version >= "3.13"
```

**国内镜像**：清华 TUNA（推荐）`https://pypi.tuna.tsinghua.edu.cn/simple`、
中科大 USTC `https://pypi.mirrors.ustc.edu.cn/simple`、阿里云 `https://mirrors.aliyun.com/pypi/simple/`。
永久换源：`python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`

> **⚠️ 常见报错**：`No matching distribution found for requests~=2.33`
> **不是镜像缺包**（镜像里有 requests 2.33/2.34），而是本机 **pip 索引缓存过期**。
> 加 `--no-cache-dir`，或先 `python -m pip cache purge`。
> **不要**用 `--no-deps`（会装出 `import deareis` 直接失败的组合）。

## 4. 快速开始

```bash
# ① 生成合规案例目录（校验器应为 0 违规）
python scripts/init_case.py ./my-case --case-name my-cell

# ② 把清洗后的数据写入 my-case/results/s1_data_clean.csv
#    列名固定：f_Hz, Z_re_ohm, Z_im_ohm

# ③ 跑多起点拟合（骨架里已生成起步脚本）
python my-case/scripts/run_fit.py my-case/results/s1_data_clean.csv

# ④ 校验输出物命名/manifest
python scripts/validate_eis_outputs.py ./my-case
```

然后把 `SKILL.md` 的 **★① 任务模板** 复制给 AI，填上数据路径即可。

> `init_case.py` 会把 `eis_core.py` **复制**进 `<case>/scripts/`（让案例自包含）；
> 技能包升级后请重新生成案例或手动覆盖这份副本，避免副本过期。

## 5. 打包与上传自检

```bash
python scripts/check_package.py <zip 或目录>
```

逐条对照本页第 1 节的结构（根目录名 = `name` 字段、根目录只允许
`SKILL.md` + `references/` + `scripts/` + `templates/`、frontmatter 五个必填字段、
无 NUL 字节、无目录条目）。上传前跑一次，能把"解析失败"挡在本地。

## 6. 常见问题

**Q：AI 说找不到这个技能？**
A：确认路径是 `<技能目录>/eis-fitting-protocol/SKILL.md`（目录名必须与 `name` 字段一致），
并新开一次会话重新扫描技能目录。

**Q：`init_case.py` 生成的骨架校验不过？**
A：正常情况下是 0 违规。若手动改过文件名或删过文件，重跑生成即可；
既有项目先 `validate_eis_outputs.py <case> --baseline=base.json` 冻结历史违规。

**Q：`eis_core.py` 能拟合别的电路吗？**
A：`eis_core.py` 只内置主电路 `[RL(RQ)(RQ)Wo]`；元素函数 `z_rq/z_wo/z_w/z_g/z_la`
可以自由组合。**多模型比较（多孔/传输线/加弧）不要改 `z_model`**，用
`pyimpspec.fit_circuit(pyimpspec.parse_cdc(cdc), data)` 或 `eis_core.z_cdc(cdc, f, values)`。
改动前先跑 `--selftest` 确认基线是绿的。

**Q：我有好几份谱（重复测量/不同状态），怎么一起处理？**
A：`python scripts/scan_batch.py <目录或文件...> --starts=200 --csv=spread.csv`。
它逐份体检+拟合，并给出**组间离散度表**与**合格性统计**（SKILL E18/E16）。
注意：先平均再拟合会把系统漂移伪装成低噪声，不要这么做。

**Q：报告里能写"找到全局最优"吗？**
A：不能。规范要求写"**已发现的最低 SSE** + 去重后的解族"，且**参数口径与阻抗口径各报一次**
（`n_distinct` / `n_distinct_spectrum`）——不可辨识方向上的参数漂移会让参数口径虚报。见 E8。

**Q：怎么跑得快一点？**
A：`global_fit` / `profile` 默认已是两阶段（松容差粗筛全部起点 → 紧容差精修最好的若干盆地代表），
同一 `seed` 下 `best_sse` 与单阶段一致到 ~1e-14、耗时约 1/2–1/7。
再快可用 `jac="analytic"`（解析 Jacobian，自检里有数值校验）。
**不要**把多进程写进核心脚本：Windows 是 spawn，从脚本/REPL 直接调用会因缺
`if __name__ == "__main__":` 抛 `RuntimeError`。
